# API·외부 연결 관리

설정의 **API·외부 연결**에서 검색 제공자, 공개 제품 소스, 기존 라벨 인식 설정을 관리한다.
기존 `#sources` 주소도 이 화면을 연다. 소스 주소·파싱 규칙은 아래 고급 설정에 있다.

## 등록·확인·사용

- **등록**은 서버에 암호화된 인증 정보가 있는지 표시한다. 여러 인증 항목 중 일부만 저장할
  수 있고, 키가 필요 없는 소스는 별도로 표시한다. 입력란을 비우면 기존 키를 유지한다.
- **연결 확인**은 버튼을 눌렀을 때만 제한된 외부 요청을 보낸다. 요금·사용량에 반영될 수
  있다. 저장된 연결을 열거나 새로고침하는 것만으로 요청하지 않는다. 성공은 해당 확인
  endpoint의 인증·응답 형식 확인이며, 원문 재사용 권리나 계정 잔액 확인을 뜻하지 않는다.
- **사용**은 독립된 일시 중지/사용 시작 선택이다. 새 연결은 일시 중지 상태로 저장한다.
  기존 설정을 이전할 때는 기존 사용 상태를 보존한다. 중지는 키를 지우지 않는다.

키·상한·소스 규칙 등이 바뀌면 revision을 올리고 이전 확인 결과를 오래된 결과로 표시한다.
늦은 결과는 동일 revision에만 기록한다. 이미 보낸 요청은 끝날 수 있지만 변경 뒤 후속 송신은
최신 연결과 소스 상태를 확인한다. 앱의 분/UTC 일 요청 **예약 수**는 제공자의 청구량·잔액과
다르다. 공식 잔액 조회가 연결되지 않은 제공자는 확인되지 않음으로 표시한다.

## 제공자와 기존 설정

네이버 API HUB와 기존 개발자센터 인증은 별도 종류다. 2026년 7월 종료된 쇼핑 상품 검색을
제공하지 않는다. 동일 연결을 참조하는 검색 기능은 연결별 요청 상한을 함께 쓴다.
Brave·Exa 확인은 최소 검색 요청을 사용한다. Exa Answer·요약·Research를 호출하지 않는다.
OpenAI 확인은 모델 목록만 요청하며 추론 호출을 하지 않는다. 라벨 인식 모델·선택형 AI
매칭 보조·월 상한은 기존 값을 보존한다. 새 탐색 기능의 AI 키 필요 여부와는 별개다.
ChatGPT 연결이나 구독이 이 앱의 API 키를 대신하지 않는다.

## 이전과 복구

`0014_provider_connections`는 기존 소스와 LLM 설정에 연결 참조를 추가한다. 기존 설정별
stable UUID를 사용하고 암호문을 해독 없이 복사한다. 마지막 네 글자가 같은 키도 합치지
않는다. 소스 override, 사용자 고정, 기존 OCR 옵션과 원본 암호문을 보존한다.

운영 적용 전에 [복구 절차](operations.md)의 백업·격리 복구·readiness 확인을 완료한다.
키 복호화 실패는 인증 오류와 구분하며 기존 암호문을 삭제하거나 자동 재발급하지 않는다.
올바른 암호화 마스터 키와 백업을 복구한 뒤 명시적으로 연결을 다시 확인한다.

이전은 PostgreSQL의 트랜잭션 DDL로 처리한다. 실패하면 원본 상태를 확인하고 수정 후
재실행한다. downgrade는 새 연결·새 연결 전용 키를 잃을 수 있으므로 운영에서 단독 실행하지
않는다. 복구 가능한 백업과 구 이미지·스키마의 호환성을 함께 확인한다. 기존 설정으로의
명시적인 키 수정·삭제는 호환 원장에도 반영하여 구 API가 오래된 키를 되살리지 않게 한다.

## 보관 경계

연결과 인증 정보는 서버 전용 테이블이다. GET 응답에는 상태·마스킹 힌트만 포함하며,
설정 응답은 `Cache-Control: no-store, private`을 사용한다. 키는 일반 동기화·export·
Dexie·outbox·서비스 워커 캐시에 넣지 않는다. 화면의 입력값은 폼 메모리에서만 유지하고
저장·닫기·계정 전환 시 버린다. 연결 해제는 키를 지우고 사용을 중지하지만 참조 소스,
사용자 고정, 구매 기록은 보존한다.
