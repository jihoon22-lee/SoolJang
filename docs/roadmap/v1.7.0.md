## 범위와 보존

다중 출처의 제품 정보·판매 조건·후기를 앱 안에서 탐색하고 외부 연결 관리·가격 관측·
동기화·복구·실물 재고 신뢰성을 개선한다. 기존 PostgreSQL/Alembic·React/Dexie 구조를 유지한다.
새 탐색의 생성형 답변·요약·LLM 호출은 제외한다. 기존 OCR/선택형 AI 설정과 사용자 키·
고정 매칭·구매·병·시음·첨부는 보존한다. 자세한 수용 조건은 #118을 따른다.

## 개발 지침 준비 작업

사용자가 기능 착수 전 별도 적용을 요청한 지침·스킬 준비 변경이다. WP01의 지침 정합성
항목에 대응하지만 B01 전체 완료로 세지 않는다. 소스 조사·평가셋·최소 계약·외부 요청
보안 구현과 실검증은 아직 별도 작업이다. 결과는
[workthrough](../../workthrough/2026-09-07-codex-workflow-optimization.md)에 기록한다.

운영 배포·유료 계약·키 발급/교체·태그 게시 권한은 계획 등록과 구분한다. 마지막으로
확인한 배포 상태를 현재 실검증으로 재사용하거나 상위 계획/명세를 준비 PR에서 닫지 않는다.
