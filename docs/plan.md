## 3. 공통 계약과 결정

- **D240 표시:** 내부 제품/주종 이동은 본문색과 무밑줄을 사용하며 버튼 의미·포커스·44px 터치 목표를 보존한다. 외부 출처 링크와 구분한다. 기존 Cellar Dark 토큰과 본문 글꼴을 재사용한다.
- **D241 시음 생명주기:** 수정은 ID·첨부를 보존한다. 삭제/복구는 조회 버전·계정·멱등 요청을 검증하고 관련 목록·Dexie를 갱신한다. 삭제는 D67에 따라 현재 잔량을 자동 복원하지 않는다. 복구도 기록만 복구한다. 현재 잔량 정정은 별도 명시적 최종값으로 처리한다.
- **D242 재고:** 현재 보유=미개봉+개봉. 제품 종류 수·누적 구매·소진·증여·판매는 별도 값이다. 상위 주종은 후손을 포함하고 하위 행과 다시 합산하지 않는다. 잔량 미기록은 0ml가 아니다.
- **D243 관심:** identity 편집은 전체 식별정보를 보존한다. 식별 변경 후 기존 고정·감시는 재확인한다. 소프트 삭제/복구는 구매·병·가격 관측·전환 영수증을 보존하고 감시는 자동 재개하지 않는다. 선택 출처 URL만 저장하고 검색 본문/발췌는 저장하지 않는다.
- **D244 검색:** 표시명·원어명·사용자 확인 별칭을 구분한다. 출처를 확인한 작은 브랜드 사전으로 한영 질의를 연결하며 빈티지·숙성·배치·용량·세트 조건을 버리지 않는다. 별칭은 제품 자동 병합·고정의 근거가 아니다. 서버·오프라인 동일 정규화·초성 규칙과 평가 자료를 사용한다.
- **D245 탐색:** 응답 도착 순서와 최종 순위를 분리한다. 원순위·질의·언어·출처를 남기고 동일 URL과 동일 제품을 구분한다. 모르는 속성/평점/가격은 생성하지 않는다. 기존 호출 상한·취소·부분 실패·no-store·allow_llm=False·출처별 권한을 유지한다.
- **D246 통계:** 관측 사실→비교 기준/표본→근거 기록→다음 행동을 제공한다. 제품 평점과 시음 평점, 같은 SKU의 가격 조건, 0원과 미기록, 현재 재고와 날짜가 있는 이벤트를 구분한다. 날짜 없는 과거 재고 추이·음용 안전 기한·자동 취향 인과 설명은 생성하지 않는다. 파생 지표를 DB에 저장하지 않는다.
- **D247 시음 정정 안전성:** 일반 저장은 평점·메모만 부분 변경한다. 고급 변경은 표시·이번 편집 확인 후 별도 적용하며 Enter 암시 제출을 막는다. 보관과 폐기를 구분하고 결과 미확정은 원요청만 재확인한다. 충돌 복구도 실제 제출 범위로 확인한다.
- **D247 수용·배포:** 자동 검사·합성 브라우저·실연결·복구·실사용자 평가·운영 확인을 구분한다. 실제 실행하지 않은 범위를 통과라고 쓰지 않는다. 배포 전 백업과 격리 복원, 배포 후 정확한 이미지/버전/스키마·기록 보존·화면 경로를 확인한다.

디자인은 기존 그린블랙 `#131f1a`, 패널 `#1b2b24`, 본문 `#ece4d3`, 보조 `#a9b3a6`,
브라스 `#c99a4a`를 유지한다. 이름·읽기 순서·정렬된 수치에 위계를 주고, 반복 입력폼을
접힌 편집 영역으로 옮긴다. 360px에서는 이름·상태 다음 줄에 규격/동작을 배치한다.
단순 장식·새 프레임워크를 추가하지 않고 실제 관리 과업의 동작·오류 회복을 디자인 기준으로 삼는다.
