# 외부 소스 조사와 검증

저장소 루트 `docs/plan.md`에서 현재 마일스톤의 소스 조사 원장과 담당 WP를 찾는다.
제공자 공식 문서와 실제 허용 경로를 확인하고 조사 시각·URL·확인 범위를 기록한다.
과거의 네트워크 실패나 카탈로그 등록을 현재 지원 여부로 단정하지 않는다.

각 소스에서 필요한 항목만 확인한다.

- 검색 제공자 / 원문 도메인 / 판매처·지점 / 제품·판본·SKU·판매 조건을 구분한다.
  같은 원문을 여러 검색엔진에서 찾은 것을 독립 소스 수로 늘리지 않는다.
- 인증·계약·robots.txt·호출 한도·표시/보관 조건과 실제 접근 경로를 확인한다.
  CAPTCHA·로그인 제한을 우회하거나 유료 가입·키 발급을 자동 수행하지 않는다.
- 요청/redirect의 대상, 비밀 전달 범위, timeout·응답 크기·retry 비용, 외부 HTML 표시를
  검토한다. 정책 확인과 코드 보안 검증은 별개이며 파싱/매칭은 순수 fixture로 검증한다.
- 소스가 제공하는 주종/언어/판본/규격/가격 조건과 필드별 출처·원문/관측 시각을 기록한다.
  사용자 고정과 기존 구매 사실을 외부 응답으로 덮어쓰지 않는다.
- 자동 동일 판정 정확도·정답 후보 회수율·추출률을 분리한다. 빈티지/배치/세트/용량이
  다른 부정 사례를 포함하고 모두 확인 필요로 바꿔 정확도가 개선됐다고 보고하지 않는다.

산출물은 `소스·역할 | 정책/문서 URL·확인일 | 계약·credential 필요 여부 | 지원 범위 |
검증 환경·실제 결과 | 제한·다음 행동`이다. 가능/조건부/검색 발견만/미지원/미검증을
구분하고 등록·인증·자료 추출·복수 판매·사용자 화면 수용을 별도 기록한다.
키 값·개인 소비 이력·보관이 허용되지 않은 원문은 증거에 넣지 않는다.

v1.7.0 새 탐색은 생성형 답변·요약·LLM 호출 없이 동작해야 한다. 기존 OCR와 선택형 AI
설정은 보존하며 자동 활성화하지 않는다. 현재 필수 소스와 최소 계약부터 검증하고,
계약/키가 없는 후보는 제한을 기록해 독립적인 구현을 계속한다. 필수 수용 조건은 임의 면제하지 않는다.
