# 실사용 흐름 WP04 — 규격 추가·재구매·구매 조건

- 기준 main `81c7819`(WP02/03 #163 통합), `feature/usage-purchase-flow`.
  아래 로컬 검증은 미커밋 변경에서 실행했다. R04/R05/R06/R11, S05~S08,
  S12~S14 및 S16~S20의 WP04 범위다.
- 기존 제품의 구매 폼에서 다른 용량을 추가하고 같은 용량은 재사용한다. 생성 응답의
  SKU를 미러 반영 전에도 임시 옵션으로 유지하고 날짜·구매처·가격·병수는 보존한다.
  동시 추가 409는 현재 제품의 살아 있는 동일 용량을 확인한 경우에만 회복한다.
- 삭제·불일치 선택을 첫 SKU로 바꾸지 않고 입력을 보존하며 저장을 막는다. 매장 등록의
  기존 제품 선택과 바코드의 SKU 맥락을 연결하고, 같은 이름의 후보는 판본·도수·용량을
  보여 준다. 바코드 연결은 사용자가 규격을 선택하고 확인한 뒤에만 수행한다.
- 구매처·날짜·용량 조건을 한 구매 건에 AND로 적용한다. 재고 있음은 그 구매에 재고가
  남은 SKU를 고른 뒤 같은 SKU의 조건 일치 과거 구매도 가격 평균에 포함한다.
  구매 조건에 맞는 행이 없으면 재고 없음으로 다시 포함하지 않는다.
- `filtered_prices`·`filtered_stock_count`를 API에 추가한다. 가격 필터·정렬·커서는
  같은 반올림 전 M 값을 사용하고, 제품 전체 지표·SKU 요약·재고 원가는 보존한다.
  상세 URL에 구매 조건을 유지하며 선택 조건/전체 이력을 전환한다. CSV도 조건 가격과
  전체 재고 원가의 열을 구분한다.
- 구매·시음 참조가 있는 SKU의 용량 변경·삭제는 HTTP/sync에서 거부한다. 삭제된 기록도
  참조로 센다. 메타데이터와 용량 무변경 PATCH는 허용한다. 깨끗한 미사용 tombstone만
  명시적 온라인 생성에서 같은 ID로 재사용하며, sync가 요청 ID를 다른 ID로 바꾸지 않는다.
- 신규 파생값 저장이나 migration은 없다. 공통 쓰기 잠금과 살아 있는 부모 검사로
  구매·병 없는 시음·관심 구매 전환·가져오기와 SKU 변경의 경합을 직렬화한다.

## 실브라우저

Chromium, API 8212/웹 5176, 별도 합성 DB에서 모든 제품·규격·구매를 **UI로 생성**했다.
최초 10개 흐름은 통과했고 390px 상세의 긴 구매처 넘침을 발견했다. 수정 후 기존 fixture로
재고 단독 조건과 모바일 목록·상세 2개를 재검증해 통과했다. 페이지 오류는 0건이다.

- 빈 제품의 첫 375ml SKU와 구매, 다른 750ml 추가 시 날짜/구매처/수량/양쪽 가격 보존,
  같은 용량의 SKU 재사용 확인.
- G07 전체 평균 A15,000→B18,000, 750ml 조건 B18,000→A24,000 확인.
  조건 가격과 전체 원가를 CSV 열·원본 API/IndexedDB로 대조했다.
- 구매 조건 URL의 상세 새로고침과 전체 이력 전환, G06 서로 다른 구매의 매장/날짜 조건을
  합치지 않음 및 재고 없음으로 재포함하지 않음 확인.
- 같은 이름의 2021 판본을 매장에서 선택해 기존 750ml에 재구매했다.
  바코드에서는 사용자가 선택한 SKU만 실제 서버에 연결하고 다시 같은 SKU로 이동했다.
- 375ml를 UI로 소진한 뒤 **용량 필터 없이 재고 있음만 적용**해 B18,000→A24,000,
  A 조건 구매 1/전체 구매 2, 전체 재고 원가 24,000원을 확인했다.
- 최종 390px 목록·상세 `scrollWidth=390`, `viewport=390`. 긴 구매처는 카드 안에서 줄바꿈된다.

바코드의 getUserMedia/video.play/BarcodeDetector와 조회 응답만 browser boundary mock이다.
실제 카메라·제공자 성공을 주장하지 않는다. 명시적 SKU 연결 PATCH는 실제 API에 반영하고
GET으로 확인했다. 강제 클릭·시계 가속·운영 데이터·유료 호출을 사용하지 않았다.
스크립트의 응답 대기·자동완성 닫기·CSV 숫자 비교 오류는 앱 결함과 구분해 수정했다.
