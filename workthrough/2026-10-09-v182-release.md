## 백업·격리 복원

운영 `1.8.1`의 API와 쓰기를 중지하고 DB+uploads 묶음을 만들었다. DB 컨테이너는 유지했다.

| 시점 | 백업 | 결과 |
|---|---|---|
| 태그 전 | `sooljang-20261009T141935982922Z-1b9a0244` | 무결성·복구 키·덤프 목차, 격리 DB/파일 실제 복원·암호문 복호화·API 조회 통과. 기존 API 재개 |
| 이미지 전환 직전 | `sooljang-20261009T145034819949Z-814d7768` | 무결성 통과, 이전 검증본과 state·uploads 일치. 이 최신 묶음도 별도 빈 DB에 다시 실제 복원·조회 통과 |

복원 대상은 격리 PostgreSQL 54329의 전용 빈 DB와 임시 uploads였다. 가격 감시 worker는 껐다.
복원본의 동일 트랜잭션 안에서만 임시 인증 정보를 사용해 실제 로그인·쿠키 인증 후 제품·구매·
병·시음·통계·보관·실사·연결·새 시음 페이지 API를 조회했다. 인증 변경은 모두 롤백했다.
행 수·스키마·첨부 참조·암호문 일치도 확인했다. 첨부 원본이 없어 대표 파일 열람은 미실행이다.
검증 후 임시 복원 DB와 파일 사본은 제거했으며 정식 백업은 보존했다.

## 운영 전환과 확인

`.env`의 `SOOLJANG_VERSION`만 1.8.2로 바꾸고 `pull api web`을 실행했다.
두 새 이미지의 revision label은 release SHA `48be241`과 일치한다.

| 구성 요소 | 게시 이미지 digest |
|---|---|
| API | `sha256:9b1050ffd70173667735a5fb3a657a0f39cf1b1180145a9dc282dd32e70c34e8` |
| 웹 | `sha256:f0fd6aded7eb693e9d9b4cb013d6a0ed6751e141d6f76f614be1d9938239a837` |

새 이미지의 `alembic upgrade head`가 성공했다(추가 migration 없음). 이어 API를
`up --no-deps --wait --wait-timeout 120`, 웹을 `up --no-deps`로 전환했다.
이전 이미지(API `f959adc7…`, 웹 `3ca0886f…`)와 DB 컨테이너 `3a44186161ed`·볼륨은 보존했다.
새 API `a877b3310325`, 웹 `719b407091b3` 모두 healthy다.

- API live/ready와 Tailscale HTTPS ready: **1.8.2**, schema `0019_record_event`,
  `schema_ready=true`, `price_watch_worker_ready=true`.
- 비로그인 `/auth/me`: **401**. 사용자 실제 로그인 화면에서의 인증은 검증하지 않았다.
- 운영 DB의 전체 행 수·스키마·첨부 참조는 전환 직전 백업과 일치하고 암호문 복호화도 통과했다.
- 별도 프로세스의 `REPEATABLE READ`·`READ ONLY` 트랜잭션으로 사용자별 통계·주종별·랭킹·
  보관·시음 조회를 검증했다. 전환 전후 업무 요약과 모든 모델 행 수의 SHA-256이 일치한다.
  새 시음 페이지도 가장 기록이 많은 병에서 첫 limit=1부터 끝까지 기존 내역과 대조했다.
  이는 내부 읽기 스모크이며 실제 사용자 로그인으로 표현하지 않는다.
- 실제 Chromium의 기존 운영 PWA 프로필에서 새 번들 활성화·로그인 화면·오프라인 앱 셸
  로딩을 확인했다. 비로그인 서비스워커 전환을 직접 확인한 것이며, 로그인한 사용자의
  업데이트 버튼·입력 보존 검증은 앞선 합성 21개 수용 근거와 구분한다.
  초기 검사에서는 비로그인 오프라인 로그인 폼 기대 및 전환 완료 전 단언을 수정·재확인했다.
- 새 API 기동 이후 로그에 ERROR·Traceback 없음. 개인 내역·키는 출력하거나 커밋하지 않았다.

배포 기록 문서 변경은 링크·버전·실행 증거·diff·secret scan으로 확인한다. 동작 코드와 이미지는
위 검증 이후 바꾸지 않았으며, 동일한 전체 테스트를 문서 변경 때문에 반복하지 않는다.
