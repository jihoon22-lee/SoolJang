## 범위와 미실행

- **운영 쓰기:** 운영 쓰기나 사용자 비밀번호를 쓴 로그인은 하지 않았다.
  - 실제 쿠키 인증은 격리 복원본에서, 운영 조회는 READ ONLY 트랜잭션에서 검증했다.
  - 보존 해시 비교의 경계는 쓰기 재개 전이다. 이후의 정상 사용·worker 변경을 데이터 손실로 해석하지 않는다.
- **운영 Secure 쿠키:** 로그인 응답의 `Set-Cookie`를 운영에서 직접 보지 않았다(비밀번호 미사용). 운영
  환경(`environment=production`)에서는 코드상 항상 Secure이며, R4 PR에서 빌드한 컨테이너로 확인했다.
- **격리 복원 DB:** 두 격리 복원 DB(`sooljang_v1110_restore_8fb8ddb12345`, `…_8939549c5824`)는 검증을 마친
  뒤 지웠다. 운영 사본을 개발 PG에 남기지 않기 위해서다. 백업 묶음 두 개는 `~/sooljang-backups`에 보존한다.
- **복귀:** 같은 schema라 이전 v1.10.1 이미지로 복귀할 수 있다. 다만 서비스 복구일 뿐 결함 해결이 아니다
  (operations §4.5).
- **미실행:**
  - 로그인한 실제 사용자의 새 기능 사용(해외 구매·매장 모드 관심·최근 삭제 시음).
  - 물리 휴대전화·iOS.
  - 실기기 푸시와 외부 유료 연결.
  - 오래 열린 모든 사용자 PWA.
  - 이 문서 커밋은 운영 이미지에 다시 배포하지 않는다.
