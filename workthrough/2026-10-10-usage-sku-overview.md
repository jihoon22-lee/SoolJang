  아래 로컬 검증은 이 PR의 미커밋 변경에서 수행했다.
- R01/R02/R03, S01~S04 표시·집계, S07/S08/S15 이동 맥락, S13/S14 계산,
  S16 재계산 및 S18~S20의 이번 변경 범위. 전체 수용은 WP06에서 별도 실행한다.
- 한 제품 항목 아래 SKU별 재고·개봉/미개봉·실평단가를 표시한다. 재고 규격 우선,
  다음은 용량/ID 순이며 지난 규격·미구매 규격을 구분한다. 단일 규격은 바로 사용할 수 있다.
- domain·SQL·웹이 구매→SKU·병→구매 연결을 보존한다. SKU 전체 유효 구매의
  실구매 총액÷병수×재고 병수를 중간 반올림 없이 계산하고 SKU별 소수 2자리 확정값을
  제품·전체 원가로 합산한다. 홈·통계·제품 CSV도 같은 원가를 사용한다.
- API `sku_summaries`와 통계 원가, 구매 생성 시각, 보관 목록 식별 정보를 추가했다.
  파생값은 저장하지 않으며 migration·IndexedDB schema 변경은 없다. SQL 요약 조회는
  제품마다 요청하지 않고 페이지 단위로 묶는다.
- 구매 참조와 용량·판본으로 반복 구매의 동일 번호 병을 구분한다. URL의 SKU/병/시음
  맥락은 현재 계정의 살아 있는 원본 연결로 검증하고 불일치는 안내한다. 목록 필터·정렬·
  더 보기·스크롤은 계정별 sessionStorage로 복원한다.
- 매장 비교는 선택 SKU의 최근·최저·가중 평균이며 외부 제안 비율도 같은 SKU 기준이다.
  판본·판매 조건이 확인된 동일 용량 KRW 단품만 비교한다. 조건 식별 없는 소스 요약에는
  비율을 붙이지 않는다. 출처·가격·확인 시각·캐시 표시는 보존하며 외부 요청/파싱 정책은
  바꾸지 않았다. 출처 검토 표의 실연결 수용 상태도 바꾸지 않는다.
