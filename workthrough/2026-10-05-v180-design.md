# v1.8.0 ③ — 디자인 정비와 빠른 시음 기록

코드 리뷰(2026-10-04) §2 디자인과 §4 빠른 기록 제안을 반영한다. 메인 [#147](https://github.com/jihoon22-lee/SoolJang/issues/147),
브랜치 `feature/v180-design`. 결정은 `docs/plan.md` D220·D221.

## 변경

**디자인 시스템(styles.css)**
- 공통 입력·select·textarea·fieldset/legend 스타일 한 벌(시음 폼의 흰 입력칸 제거), `color-scheme: dark`.
- `--warn`(확인 필요)과 `--danger`(실패) 분리, 차트 3번 색을 위험색과 분리, 간격 토큰 16/24/32px.
- 화면 제목 `page-title`(크기·하단 경계선), 표 머리글 대문자 변환 제거, 표 셀 밀도 변수와
  설정의 "표 밀도"(넉넉하게/촘촘하게, 기기별).
- `button.btn-quiet`, 위험 버튼 hover 배경, 터치 기기에서 작은 버튼 44px, `prefers-reduced-motion`,
  safe-area, 모바일 이중 스크롤 제거, 지표 숫자는 고정폭 본문 숫자.
- 모바일(<600px) 하단 탭바, 헤더는 제목·동기화·설정만. 동기화 배지는 점+건수(접근성 이름 유지).

**화면**
- 홈: "오늘 마셨어요", 동기화 대기 알림, 핵심 지표 3개+보조 한 줄, 지금 열려 있는 병,
  바로가기(보관·실사·가격 감시·데이터 품질), 주종별 비율 막대.
- 빠른 시음 시트(`QuickTastingSheet`): 열린 병 먼저, 미개봉은 술마다 한 줄로 묶고 고르면 개봉.
  별점(`RatingStars`, 같은 별 다시 누르면 0.5 내림)·양 프리셋(30/50/100/150ml)·접힌 상세, 직전
  장소·동석자 기억(`sync/tastingActions.ts` 공용 기록 로직).
- 병 패널의 시음 폼도 같은 입력(`TastingFields`)으로 교체.
- 제품 상세: 제품명을 크게, 메타 정보는 칩 한 줄, 핵심 지표 3개+"지표 더 보기", 삭제는 "⋯" 메뉴로,
  구매 이력 표 줄바꿈 방지, 구매 수정/삭제 버튼에 구분되는 접근성 이름.
- 통계: 요약·주종별·랭킹·피벗·추이 탭, 요약은 핵심 3개+더 보기.
- 내 술: 도구 막대 한 줄(모바일 가로 넘김, 주 동작 맨 앞), 카드 2줄 요약, 결과가 없으면 적용 중인
  조건 칩과 "조건 모두 해제", 목록 끝에서 자동으로 다음 묶음, 정렬 방향은 화살표 토글.
- 공통 `LoadingState`/`EmptyState`/`InlineError`.

**접근성**
- 설정 메뉴: `role="menu"` 대신 disclosure 내비게이션, 열면 첫 항목 초점, Esc 시 버튼으로 복귀.
- 화면 이동 시 `document.title` 갱신·본문 초점, 바코드 패널은 모달(초점 가두기·Esc·다시 스캔).
- 제품 폼 필드별 `aria-invalid`·`aria-describedby`·초점 이동, 숫자 칸 `inputMode`.
- 차트 컨테이너 `role="img"` → `figure`(막대 안 주종 버튼과 대체 표가 보조기술에서 가려지던 문제).
  도넛 범례에 비율 병기, 막대 행 터치 크기.
