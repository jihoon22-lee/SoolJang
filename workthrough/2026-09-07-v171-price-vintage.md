# v1.7.1 — 구매 가격 공란과 빈티지 근거 보존

개인 구매 가격 공란을 미상으로 분류하고 평균 분모에서 제외해 선물·포인트 취득의
가격과 원가를 잘못 표시했다. 또한 별도 등록 빈티지보다 이름의 연도를 우선했고,
외부 상세 필드의 빈티지 등을 관측 저장에서 누락해 마지막 정상 관측 재계산이 달라졌다.

## 변경

- 구매의 정가/실구매가 공란은0원이다. Python·SQL·오프라인 계산, 구매 상세·통계·
  구매처 지출·품질 화면을 일치시킨다. 유료1병3만원+선물2병의 평균은1만원이다.
  구매 자체가 없는 평균, 정가0원의 할인율, 미취득 외부 판매가를0으로 만들지는 않는다.
- 기존 DB·동기화 원본NULL과 개인 기록을 보존하고 조회/계산 경계에서 의미를 바로잡는다.
  구매 분할의 명시적 가격null은0원, 생략한 필드는 기존값을 상속한다. schema0018 유지.
- 등록 빈티지를 상품명보다 우선한다. 외부 상세 빈티지·도수·숙성·생산자 근거를
  JSON 관측으로 보존하고 재조회에서도 같은 판정을 유지한다. 다른 빈티지·모순된
  상세는 계속 확인 필요다. 과거에 보존되지 않은 출처 필드를 임의 복원하지 않는다.
- 버전3곳과 두 lockfile을1.7.1로 맞추고 현재 안내·도메인 규칙·계획·운영 문서를 갱신한다.
  원래 v1.7.0 검증 이력은 유지하며 #142/#143은 별도 후속이다.
