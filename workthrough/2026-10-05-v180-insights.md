# v1.8.0 ④ — 변경 이력·규격별 지표·개봉 알림·CSV·동기화 대기열

코드 리뷰(2026-10-04) §4 추가 기능 제안을 반영한다. 메인 [#147](https://github.com/jihoon22-lee/SoolJang/issues/147),
브랜치 `feature/v180-insights`. 결정은 `docs/plan.md` D222·D223.

## 변경

**서버 — 변경 이력(schema 0019)**
- `record_event` 테이블(additive). 병 개봉·소진·증여·판매·되돌리기·개봉 취소·잔량 조정·시음으로 인한
  병 변화, 구매 수정(구매일·구매처·가격·병수)을 바뀐 칸만 [이전, 이후]로 남긴다. 온라인 API와 동기화
  배치가 같은 서비스 함수를 거쳐 한 번만 남는다. 과거 이력은 소급하지 않는다.
- `GET /bottles/{id}/history`(위치 이동 `bottle_movement` 포함), `GET /purchases/{id}/history`.
- 금액은 정규화해 "9000"과 "9000.00"을 같은 값으로 본다.

**웹**
- 병 패널·구매 수정 폼에 "변경 이력"(펼칠 때만 불러옴, 온라인 전용).
- 제품 상세 "용량별" 표: 용량이 2개 이상이면 용량마다 구매·재고·실평단가·100ml당.
- 홈 "빨리 마시면 좋은 병": 권장 기간을 넘긴 열린 병(주종 이름 기준, 증류주 제외).
- CSV 내보내기: 내 술(현재 필터·정렬 그대로), 실사 미확인·불일치. UTF-8 BOM, 수식 주입 방지.
- 동기화 패널: 보낼 기록 목록과 "지금 동기화", 실패가 여러 건이면 "모두 다시 보내기"(새 키로
  재전송)·"모두 건너뛰기"(의존 명령 포함). 대기 기록만 있어도 배지로 패널을 연다.

  새 테스트: CSV 이스케이프·수식 방지·BOM, 권장 기간·경과일, 이력 문장·지연 로딩·오프라인 안내,
