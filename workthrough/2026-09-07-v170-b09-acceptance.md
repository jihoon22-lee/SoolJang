# v1.7.0 B09 — 통합 수용·첨부 복구·실행 환경

WP13 #131, R01~R24/S01~S12의 구현·증거 연결과 WP03의 첨부 열람 공백을 처리했다.
[수용 원장](../docs/plans/v1.7.0/acceptance.md)에 전체 R/S와 PR를 연결했다.
**구현 PR B01~B08은 CI 통과·머지됐지만 실제 국내 가격 2출처의 허용 범위와 운영 수용은
미완료다. 마일스톤·릴리스 완료로 판정하지 않았다.**

## 변경·검증 기준

- B07 `b7861b1` + 복구/첨부 `7929009`를 합친 `8ab59ee`에서 전체 회귀와 실제 브라우저를
  실행했다. B07 main merge `a364147`을 통합한 후 `b56db33`에 Docker/개발 감시를 보강했다.
- 인증 `GET /attachments?product_id=…`, `GET /attachments/{id}/content`와 제품 상세의 접이식
  이미지 열람을 추가했다. 본인 소유의 살아 있는 대상만 읽고, 경로 각 구성요소를 디렉터리
  FD 기준 `O_NOFOLLOW`로 연다. 정규파일·상한·MIME/확장자·DB길이·SHA256을 같은 열린
  FD에서 검증한다. private/no-store·nosniff·제한 CSP·UUID filename을 사용한다.
- 복구 opt-in은 12개 관련 원장, 암호문 digest, 관심/고정·가격 관측·실사, API 10종과 원본
  PNG GET을 대조한다. 복원된 불확실한 `sending`은 `unknown`으로 보존하고 재전송하지 않는다.
- 실제 새 Docker volume이 root 소유여서 UID1001 앱에 쓰기 불가인 결함을 재현했다.
  이미지에서 `/app/uploads` 소유권을 준비해 새 named volume에도 전달한다. 기존 운영 볼륨
  소유권이나 파일은 변경하지 않았다. `.dockerignore`로 비밀·로컬 산출물을 빌드 context에서 뺐다.
- Vite의 무조건 polling을 기본 파일 감시로 바꾸고, Windows 마운트에서 필요한 실행만
  `SOOLJANG_WATCH_POLLING=1`을 선택한다. 실제 config 로딩에서 unset→false/1→true를 확인했다.

## 실제 브라우저·복구 범위

1. **401 outbox**: 두 탭에서 200/200/1, 두 번째200건 DB commit 후 응답 유실 시
   200/200/200(같은 ID 재시도)/1. 성공 결과 순서를 역순으로 전달해도 확인한 ID만 제거한다.
   확인 뒤 남은201개 ID를 원래 집합과 대조했다. 최대 동시 배치1, 서버 고유401,
   최종 outbox/손실/중복/pageerror 모두0.
2. **새 폼 SW**: 탐색·목표가 작성 중 업데이트 버튼이 비활성이고, 깨끗한 세 번째 탭에서
   실제 SW를 활성화해도 두 입력이 유지됐다. 브라우저 프로세스 종료 후 오프라인 셸과 탐색
   입력을 복원했다. 목표가 draft도 보존되며 가격 이력을 인증 조회할 수 있는 재접속 뒤 폼에서
   복원했다. 가격 이력의 오프라인 캐시를 제공한 결과는 아니다.
3. **제품 연결**: 제품 가격 이력→관심 저장 버튼→공통 탐색 패널→관심 저장에서 기존700ml
   SKU·제품 pin·선호판매처를 그대로 보존했다. 조회 HTTP0·pageerror0.
4. **복원 첨부**: 실제 bundle을 별도 `_restored` DB/uploads에 복원한 API8241/웹5201에서
   합성 PNG가 디코딩됐다. 소유자200/비로그인401/다른 계정의 원본·목록404, 390px 가로 넘침0.
   1×1 PNG는 원본 보존·인증 확인용이며 큰 사진이나 기기별 HEIC 표시를 검증한 것은 아니다.

**1078병은 고정 합성 fixture이며 현재 운영 데이터 수를 의미하지 않는다.**

제한된 조회가 일치 제품/offer0을 반환한 뒤 Exa10문서·9도메인·후기 분류2건을 보여주고
관심 저장·구매 합계 불변을 확인했다([metadata](assets/v170-b09-discovery-fallback.json)).
전체 Dailyshot 카탈로그 부재나 모든 문서의 정확한 판본 일치를 증명하지 않는다. 원문·가격을
저장하지 않았다. Exa 실송신은 이 시나리오1회를 포함해 전체 세션11회이며 B05의6주종 자료
