# v1.8.0 ⑤ — 문서 통폐합과 최신화

사용자 요청 "불필요한 문서는 통폐합하고 최신화"에 따른 정리. 메인 [#147](https://github.com/jihoon22-lee/SoolJang/issues/147),
브랜치 `feature/v180-docs`. 코드 동작은 바뀌지 않는다(주석 두 곳의 문서 참조만 고침).

## 검증

- 저장소 전체 Markdown 상대 링크 검사(스크립트): 깨진 링크 0(이 기록 추가 전에는 이 파일 하나).
- 삭제 문서 이름 검색: 지난 workthrough 본문 서술과 history.md 고정 링크 외 참조 없음.
- `external-data.md`의 수치를 코드와 대조: `SNAPSHOT_VERSION = 4`, 탐색 소스 최대 4개
  (`schemas/discovery.py`), 하루 기본 상한 1000(`external_request_usage.py`).
- `architecture.md` §4.2 엔드포인트 표는 실행 중인 API의 OpenAPI에서 생성(137개 경로·메서드).
- `uv run ruff check src`, `uv run ruff format --check src` 통과(주석 줄바꿈).

  실제로 따라 하며 확인한다.
