# v1.8.0 ② — 여러 술·병 일괄 처리

코드 리뷰(2026-10-04) §1의 일괄 처리 항목을 반영한다. 메인 [#147](https://github.com/jihoon22-lee/SoolJang/issues/147),
브랜치 `feature/v180-bulk-records`. 결정은 `docs/plan.md` D217~D219.

## 변경

**병 (제품 상세)**
- `BottleSection`: "여러 병 선택" → 재고 전체 선택·개별 체크 → 하단 동작 막대(개봉·소진·증여·판매·
  위치 이동). 지금 상태에서 할 수 없는 병은 건너뛰고 가능한 수를 버튼에 표시한다.
- 처리 직후 "실행 취소" 토스트(역방향 전이: `reopen`/`unopen`/`set_remaining`, 위치는 원래 위치별로).
- 선택 없이 쓰는 빠른 동작: "한 병 개봉(n번)", "개봉한 병 다 마심(n번)".
- 구매가 여러 건이면 병마다 구매일·구매처를 표시하고, 지난 병이 3개를 넘으면 접는다.
- 증여·판매는 `window.confirm` 대신 날짜·메모 시트(`HandOverSheet`, 서버 `on`·`note` 사용).
- 개봉 병 잔량 조정(`RemainingEditor`: 약 3/4·절반·약 1/4·직접 입력·다 마심).
- 공용 모듈 `sync/bottleActions.ts`(전이 규칙·낙관적 필드·일괄 적용·되돌리기), `components/Toast.tsx`.

**구매**
- 구매 이력 행에 "수정"(구매일·구매처·정가·실구매가·병수). 서버 `PATCH /purchases/{id}`가
  `quantity`를 받아 병을 추가하거나 번호가 큰 미개봉 병만 지운다(부족하면 409, 동기화 경로는 거부).
- 구매 추가 성공 시 폼을 닫고 알림. 가격·병수 입력에 `inputMode`/`step` 지정.

**내 술 목록**
- 선택 모드: 필터 결과 전체 선택, 표 머리글 체크박스, 필터 밖 선택은 동작에서 제외하고 개수 표시.
- 일괄 주종 변경·삭제를 outbox로 처리(오프라인 가능). 주종 변경은 실행 취소, 삭제는 함께 지워질
  병 수 확인 후 하위까지 연쇄(`sync/productDelete.ts` 공용화).

**보관·실사**
- 탭(병 위치 / 위치 관리 / 재고 실사)과 진행 중 실사 배너.
- 병 위치 표: 위치·이름 필터, 체크박스, 하단 막대로 일괄 이동 + 실행 취소. 서버
  `PUT /collection/bottles:move`(원자적).
- 실사: 진행률(확인/예정·불일치·예정 밖), 카메라를 켠 채 연속 스캔(중복 2.5초 무시·진동),
  "위치 불일치 n병을 확인한 위치로 옮기기"(`:apply-locations`), 미확인 병을 골라 일괄 소진,
  `scans:batch`(항목별 결과) API.

**데이터 품질**
- 사유별 목록에서 바로 골라 하단 막대로 고친다(주종·구매처). 이름 없는 구매는
  "제품명 · 날짜 · 병수"로 표시(UUID 노출 제거). 구매처 중복은 한쪽으로 합치기 미리보기.
- 품질 보고서는 삭제된 제품의 하위 행을 제외하고 0원 구매 수를 알린다.

## 미실행·제한

- 실브라우저·실제 카메라 연속 스캔은 묶음 ⑥에서 합성 데이터로 확인한다(jsdom은 카메라 mock).
- 일괄 동작의 서버 반영은 기존 동기화 계약(충돌=conflict, 입력 오류=실패 큐)을 그대로 따른다.
